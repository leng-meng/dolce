# 排版：「展开 / 原样」两档

**判据全录** → 无单独实现篇；两档共用的简谱引擎见 [排版-简谱引擎.md](排版-简谱引擎.md)

## 职责

**两档的唯一语义是「排版方式」**，不是版式主题、也不是文档格式的分支：

| 档 | 语义 | 用途 |
|---|---|---|
| **展开** | 反复与多段歌词**逐遍展开**，一段歌词一遍谱、逐遍成页 | 投影（一屏一段） |
| **原样** | 按原谱排一遍，多段歌词叠在同一条谱行下、反复不展开 | 印刷歌本 |

**`.jpwabc` 与文本谱两种格式语义完全一致**，公共那一半在 `src/jianpu/`。
纸张、字号、配色**不属于这两档的分野**——它们是独立设置项，两档各记各的一套。

## 入口

| 文件 | 作用 |
|---|---|
| `src/jianpu/profile.ts` | 档位 `JianpuLayoutMode = "expanded"\|"original"`；`jpProfile`/`originalProfile` 只是两路各记的档名（`originalProfile` 管走原样文档布局的文本谱、MusicXML、多声部 123/ABC） |
| `src/layout/jianpupages.ts::layoutExpandedPages` | **展开档排页，两种格式共用一个**（吃简谱引擎输入 + 展开档样式；由 `ScorePainter` 的 `expanded` 请求调用） |
| `src/jianpu/vertical.ts` | 纵向分页 `paginate`（只认块的占位盒，两格式共用） |
| `src/jianpu/expand.ts` | `walkPlay` 按 `PlayItem[]` 逐遍逐小节回调；原样档走 `identityPlan` |

| `src/layout/original/place/expand.ts` | **原样文档引擎的展开档**（简谱合并子计划 5，开发开关 `dolce-dev-one-engine` 下才走）：按 `PlayItem[]` 从行视图切小节、逐遍接成一长行、逐行装满，拼成「展开后的」行视图交给 `layoutSong` |

原样档都由 `layout/painter.ts::ScorePainter` 排，布局算法两套：`.jpwabc` 与**单声部**的 123/ABC 走简谱引擎
（后两者经 `jianpuInputOfDoc` 投影，由 `FormatCaps.originalLayout` 与 `App._originalOnJianpu` 判）；文本谱、MusicXML 与多声部的 123/ABC
走原样文档布局 `layout/original/`（`place/` 定位、`compose/` 构图，印刷原版观感）。

## 关键判据

- **原样文档引擎的展开档**（`place/expand.ts`，开关下；页数、每页行数要与简谱引擎展开档一致，用户定）：
  - 只排第一首、只排带歌词的那个声部（同 `jianpuInputOfDoc` 的 `forExpanded`）；小节切法同 `pu/phrasesong.ts::buildMeasures`（演唱顺序的 `mid` 按它数）；
  - 每遍只挂段号区间罩住本遍遍号的那行词（同 `NoteEntry.addLyric`），同号歌词顺延（`distinctVerses`）；音符身份带 `pass`（是段号，不是第几遍）；
  - 只要旋律与词：和弦、段落词、奏法、力度/术语、小节线上的跳转字、松叶、临时伴奏都不画，延长记号与倚音留着（倚音用户定保留，两个引擎都改）；房号不画；
    唱了不止一遍的小节反复线画成普通线；小节线样式同简谱引擎（`.jpwabc` 一律细线、整首最后一条画终止线；其余格式照源，整首末条细线补成终止线）；
  - 断行：源里的换行照断（`.jpwabc` 断在行末那个符号后、其余格式断在那个小节末，同 `breakAfterChord` / `breakAtMeasureEnd`），
    换页照源（文本谱 `[fenye]`、`.jpwabc` 模型上的换页）；其间按自然宽**逐行装满**（同 `Line.doLineBreak`：占位与歌词字取并集，
    放不下退回本行末条小节线后断，`‖:` 断在它前面，只剩小节线的行并回上一行）；一遍一页起头；
  - `.jpwabc` 的 `.Layout`（`BreakPoints` / `LinesPerPage`）：源里换行与遍末换页都不认，按时值插换行 / 换页、`{}` 段不排（同 `breakByDur`）；
  - 纵向：谱行占位盒同简谱引擎谱行 Group（数字、歌词按字体盒），块间 `staffDist`、放不满的页把行距摊到 `systemSpread` 并居中（同 `layoutVertically`）；
  - 第一页是标题页（首行基线 0.3 页高，逐行下移本行字号，歌词字不加粗），谱页页脚曲名 + 「i/n」（同 `titlePage` / `addFooters`）。
  - 与简谱引擎差的（39 份 × 4 档里 3 档）：自然宽相差几 pt 的边界行、原样文档临时记号硬让位（用户定）比简谱引擎宽、谱行占位盒差 1pt 的边界页。
- **成书**（`OriginalDocumentConfig.book`，`rebuild` 缺省走它，见 [排版-成书](排版-成书.md)）：原样档的内容 + 展开档的纵向与共基线数字、「-」字；
  不展开反复、不放页眉页脚标题页；断行照文档里的断点（断句写进去的），**单行放不下才折**（`place/reflow.ts::foldLineStarts` 逐行跑 `fillLines`，
  折点经 `applyBreaks` 写回克隆再排；原样档那套「放不下整首重断」不用）。`measure` 开关只量整首自然坐标（`naturalSpans`，键为元素 id）。
- 段号让出版心左缘按首字**实际**位置算（`compose/page.ts::systemMetrics` 的 `labelLeft`，同 `paintLyricAnnotations` 的落点）。

- 「这首歌唱成什么样」**一律由 `score/playorder.ts` 从 `ScoreDoc` 推**：简谱形状（文本谱/123/ABC/`.jpwabc`）经 `model/playsong.ts::playDataOfSong`
  （`.jpwabc` 照 `.Repeat` 或按段逐遍），MusicXML 形状经 `model/playdoc.ts::playDataOfDoc`，投影时填进引擎输入的 `playData`。
- **房号（一房、二房的括线）只在原样档画**：展开档已逐遍展开，房号没有意义。简谱引擎靠 `LayoutOptions.endingSize` 开关——
  原样档取 `tuplet` 角色的字号（print 主题 0.6em，同三连音数字），展开档的 pptx 预设不设、保持 0，成书另由书样式给。
  画法与五线谱共用 `engrave/ending.ts::addEndingBracket`（横线 + 可选两脚 + 房号），竖脚长照五线谱与房号字号等长
  （成书用实测短脚 `bracketFoot`）。**房号纵向从横线往下算**（`labelBaseline`：半个线宽 + 0.3 个字号的空 + 房号墨迹上伸高），
  不按字号或竖脚长估，所以文字永远不与横线相压。`Line.addEnding` 的判据：
  - 竖脚**对齐小节线的线位**（起点前一条小节线的最后一根线、终点后一条的第一根线）；
  - 高度算上区间内与两端小节线的墨迹上沿，并按「竖脚与房号底」更深的那个让开下方，不粘连小节线、音符与和弦；
  - 封口照模型里的 `stop` / `discontinue` 画（各格式的约定在读入时定：123/ABC 最后一房不封口，见
    [../格式/123格式.md](../格式/123格式.md) §6.1；MusicXML、文本谱照原文），排版器不自己判断；
  - 房跨行时把行末仍开着的房号交给下一行，续段不画左脚、不重印房号。
- **换页口径只在 `walkPlay` 里判**：`endOfPass`（`.Repeat` 的 `P`、按段数逐遍）与**往回跳**
  （反复、D.C./D.S.）处换页；遍号变了但往前接着唱的（二房后的尾段）**不换**。源里的 `$` 强制分页另算。
- 四档视图 `ViewMode` 是**两组正交状态的组合**，不是四个视图：展开/原样走简谱（或文本谱）排版器，
  五线谱/混排也走 `ScorePainter`（差别只在 `mixedShowJianpuLayer`）。默认**展开**。
- **纸张宽度全仓一份**：`styles.css` 的 `--score-page-max`（960px），四档连同识别叠加视图共用。
  变量里**只放上限、别把整条 calc 放进去**——自定义属性里的 `var()` 在声明它的那个元素上就替换掉了。
- 纸与字号两档各记各的：展开档取 `PAGE_RATIOS`（16:9/4:3，1 单位 = 1pt，**恒分页**）；
  原样档取 `PAPER_SIZES` 实际尺寸 + 一档**长图**（出厂默认，宽同 500 首那张纸 `150×216mm`，425pt；原样档出厂音符字号 12，同 500 首；各格式同一张纸、同一套字号）。
  **「换纸」与「要不要分页」本来就是同一个决定**，所以长图是纸张列表里的一档而非勾选框。
- 导出 PPTX 取的是**展开档**那一套，哪怕屏幕正停在原样档。
- 「每页行数」（写进 `.Layout`）**只归展开档**——原样档行数由内容与纸说了算，人为定死只会把谱挤坏。
- 原样档分页时标题块排在**第一页顶上**而不是另起标题页（`LayoutOptions.bookHead`），首页可用高度按量出来的块高扣减
  （`firstPageHeadroom`，由 `jianpupages.ts::layoutOriginalPages` 填）。纸顶照 500 首重排排（`jianpupages.ts::bookHead`）：标题居中、
  **调号拍号在左**（`1=♭B ⁴⁄₄`，升降号提到音名之前、小一号并抬高）、**词曲署名右对齐逐行**，调号拍号基线与最后一行署名齐。
  挂标题块要**另包一层 Group**（见 [排版-简谱引擎.md](排版-简谱引擎.md)）。
  标题块与第一条谱行之间空 1.5 个音符字号（`headGap`，= 缺省上边距；不直接取上边距，给了大边距时标题下会空一大片）。
- **原样档的尺寸照 500 首，不照投影片**（用户定：28 是展开档的大字号，与原样档无关）：笔画按音符字号的比例给
  （出厂值写在样式表里——`style/themes.ts` 的 print 主题，em = 音符字号、取两位有效数字或常见分数：小节线 1/14、终止线粗线 1/8、
  减时线 0.05、弧厚 0.2、弧顶上下限 0.45 / 0.28、拍号分数线 0.025、多段歌词行距 1.25；角色字号歌词 1、和弦 0.85、标题 1.8、署名 0.9、
  房号与三连音 0.6、段落词 0.65，落到 pt 取整或 .5；和弦排成纯文本），适配器 `style/jianpu.ts` 里不留数。纸张表里有 500 首那张 `150×216mm`（425×612pt）。
- **原样档整首重新断行**（`LayoutOptions.reflowOverflow`、`layout.ts::reflowBreak`，用户定）：源里每一行都放得下就照原文的行；
  有一行放不下（窄纸，如 500 首那张 150×216mm），就不认源里的换行，只在小节线处断、求各行余白平方和最小——行长均匀、中间没有短行。
  源里的换页仍是硬断点；拿掉换行后挨上的 `|` + `‖:` 先并成一条。长图与分页纸同宽，一样做。
- **原样文档布局的版心与页眉**（`layout/original/`）：连谱号、段号也收在版心里（用户定）——先排一遍量出它们伸出音符起点多少，
  版心左缘让出这一截整份重排（`compose/index.ts` 的 `leftIndent`，断行按变窄的版心重求）。页眉（`place/header.ts`，排法同 `jianpupages.ts::bookHead`）右侧 `TR:` 在上、`Z:` 词曲接在下面排成一列、紧接标题块，调号拍号与最后一行署名同基线；
  一条署名里换了行（MusicXML `<creator>` 的「作词：…\n作曲：…」）照原样分行。标题不跟谱里的字体族（500 首写的魏碑只有一种字重），一律粗体。
  长图把多首接成一张时**每首的页眉、页脚都在**（`PlacedPage.headers`，页脚按首找本曲最低一行）。多条 `W:` 文字行各占一行。
- **原样文档的头顶各槽**：转调标签与和弦/注释同在一个音上时转调贴音、和弦/注释叠到上一行；注释横向压到邻音和弦的也抬一行；
  带和弦的音上力度、术语摞在和弦之上；跳房子横线让开房内和弦/注释（房号与和弦不在同一高度，一行同高）；
  延长记号、力度让弧（弧压在带它们的音上时摞到弧顶之上）；松叶两端让开起止音上的力度字。
  页眉 `TL:` / `TR:` 开头的空行不算，左右两块顶部对齐。多连音照样式键 `tuplet-style`：出厂括线（同 500 首），番茄、诗歌本风格两段弧。
- **展开档不画反复记号**（`Line.load` 的 `unrolled`）：反复已经逐遍展开（有小节被唱了不止一遍），`‖:` `:‖` 连同反复线的粗线一起去掉；
  演唱顺序是一遍过的（没认出反复）照原样留着。房号括线本来就只在原样档画。
- **放不下时在小节线处断**（`layout.ts::doLineBreak`）：照条目贪心会把一个小节劈成两半（窄纸上 `2· 3 2·· 3` 的后半截单独成行）；
  退回到本行最后一条小节线之后（`‖:` 断在它前面），一行里连一条小节线都没有才在小节中间断。
- 展开档笔画见 `style/jianpu.ts` 的 `pptx` 预设，几处**刻意背离**：小节线高度用原样档那份、三种点同半径、
  减时线与旧式八度点阶梯照 2019 年成品 .pptx。

## 已知限制

- 文本谱展开档**只排一条旋律**（`Layout` 只排 `parts[0]`）；和弦与首调号拍号不出现
- `.jpwabc` 某些曲目的歌词归属语义未定（同一小节被两条 W 行认领时谁优先）
- D.C. 那一遍无词时整页无词（「D.C. 该配哪几段词」待定）
- 横向排法已收敛：原样文档布局（`layout/original/place/spacing.ts`）同拍位归一列、判据搬自简谱引擎，单声部多声部同一份；
  分页、段号缩进、段落词缩进仍两边各一套（简谱合并成一个引擎的子计划 4、5 接着收）

具体曲目的未修版面问题记在本地私有仓库的遗留问题清单（不入库）。
